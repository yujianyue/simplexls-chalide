## I. Что это такое

`SimpleXLS` — это **чистый PHP, однофайловый** ридер книг Excel 97–2003 `.xls` (BIFF5/8). Ему не нужны расширения, кроме `mbstring` (включено по умолчанию); работает на PHP 5.5 и выше.

Эта библиотека — **xls-близнец** `SimpleXLSX` (версии xlsx). Стиль API намеренно сделан параллельным, чтобы один код обрабатывал оба формата Excel — старый и новый.

### Что он делает

- Разбирает `.xls` в PHP-массив (2-D); несколько листов, даты, числа, строки
- **Объединённые ячейки**: HTML сохраняет настоящие `rowspan` / `colspan`; CSV/TSV автоматически заполняет каждую ячейку объединения значением из левого верхнего угла
- **Извлечение изображений**: чистый PHP-разбор встроенных OLE-фигур Escher, запись изображений ячеек в `img/` и пометка ячеек `img:img/...`
- **Восстановление стилей**: превращает шрифты, цвета заливки, выравнивание и границы Excel в CSS, создавая HTML, близкий к исходному листу
- Экспорт в **HTML / CSV / TSV**

### Чего он НЕ делает

- Не умеет **записывать** xls (только чтение)
- Не считает формулы (нет движка формул — ячейки возвращают только сохранённые значения)
- Нет поддержки макросов, сводных таблиц, рядов данных диаграмм
- Для очень больших файлов (десятки МБ) читайте порциями через `rows($n, $limit)`, а не одним `toArray()`

### Основная информация

| Пункт | Значение |
|---|---|
| Один файл | `xls.php` |
| Класс | `SimpleXLS` |
| Пространство имён | нет (глобальный класс, дружелюбен к старым проектам) |
| Требуемое расш. | только `mbstring` |
| Совместимость PHP | 5.5+ / 7.0+ / 7.x |
| Версия | `SimpleXLS::buildInfo()` → `версия / дата сборки / размер / MD5-8` |

```php
require_once __DIR__ . '/xls.php';
echo SimpleXLS::buildInfo();
// напр. 2.1-style-xfext / 2026-10-13 / 56.8KB / ad039f85
```

> После развёртывания, если отрисовка выглядит неверно, **сначала проверьте этот отпечаток**, чтобы убедиться, что вы не используете устаревшую копию (старые копии не содержат последних исправлений стилей).

## II. Требования и установка

### 2.1 Системные требования

- PHP ≥ 5.5 (рекомендуется 7.0+; библиотека избегает синтаксиса 7.1+, чтобы оставаться совместимой с 7.0)
- Расширение: `mbstring` (безопасная работа с многобайтовыми строками)
- Не нужны `zip`, `xmlreader`, `gd`, `curl`
- Извлечение изображений — чистый PHP-разбор байтов: исходные байты записываются на диск без `gd` (PNG/JPG/GIF/WMF/EMF…)

### 2.2 Подключение одним файлом

Поместите `xls.php` в любое место проекта и сделайте `require_once`:

```php
require_once __DIR__ . '/lib/xls.php';
$xls = SimpleXLS::parse('demo.xls');
```

### 2.3 Использование в фреймворке

Laravel / ThinkPHP / обычные сайты требуют только одного `require_once`; конфликта автозагрузки нет. Если включён `mbstring.func_overload`, библиотека адаптируется автоматически через обёртки `_strlen` / `_substr`.

> Если в проекте через Composer загружен `shuchkin/simplexlsx`, имя класса `SimpleXLSX` **не конфликтует** с `SimpleXLS` этой библиотеки — оба можно подключить.

## III. Быстрый старт за 5 минут

### 3.1 Минимальный пример

```php
require_once __DIR__ . '/xls.php';

$xls = SimpleXLS::parse('book.xls');
if (!$xls) {
    die('Ошибка разбора: ' . SimpleXLS::parseError());
}

foreach ($xls->rows() as $row) {
    print_r($row);
}

echo $xls->toHTML();   // таблица HTML со стилями
echo $xls->toCSV();    // CSV (с BOM, кириллица открывается в Excel без кракозябр)
```

### 3.2 Три способа открыть

| Метод | Назначение | Пример |
|---|---|---|
| `SimpleXLS::parse($path)` | разбор по **пути к файлу** | `SimpleXLS::parse('a.xls')` |
| `SimpleXLS::parse($data, true)` | разбор по **байтам строки** | `SimpleXLS::parse($bytes, true)` |
| `new SimpleXLS($filename, $isData=false)` | OOP-конструктор | `$x = new SimpleXLS('a.xls')` |

```php
// 1) путь к файлу
$xls = SimpleXLS::parse('/var/data/report.xls');

// 2) байты строки (напр. из BLOB БД или временного файла загрузки)
$bytes = file_get_contents($_FILES['xls']['tmp_name']);
$xls = SimpleXLS::parse($bytes, true);

// 3) OOP
$xls = new SimpleXLS('report.xls');
```

### 3.3 Режим отладки

Третий аргумент `parse()` (или второй `parseFile` / `parseData`) — это `$debug`:

```php
$xls = SimpleXLS::parse('book.xls', false, true); // отладка вкл.
```

Когда включён, через `error_log()` выводится информация уровня записей разбора — полезно для «лист читается не полностью» или «ячейка пуста».

## IV. Основные понятия: как читается xls

Поймите эти три момента — и вы обойдёте 90% подводных камней.

### 4.1 xls — это составной документ OLE

`.xls` (BIFF5/8) по сути является **составным документом OLE2** (тот же род, что старые .doc / .ppt) — внутренняя мини-файловая система:

- поток **Workbook / Book**: все данные листов (записи BIFF)
- поток **Pictures**: встроенные байты изображений
- **Root Entry** и каталог: описывают хранение каждого потока (большой / малый блок)

Библиотека разбирает OLE чистым PHP, автоматически обрабатывая оба вида хранения (большой и малый блок — LibreOffice и Excel отличаются) и выбирает правильный поток по магическому числу (`Workbook` → `BOF 0x0809`, `Pictures` → `0xF001`).

### 4.2 Структура записи BIFF

Данные — не XML, а поток **записей BIFF**:

```
[opcode:2][length:2][body:length]   (может продолжаться через CONTINUE 0x3C)
```

Ключевые записи:

| Запись | opcode | Значение |
|---|---|---|
| BOF | 0x0809 | начало файла/потока |
| EOF | 0x000A | конец |
| BOUNDSHEET | 0x0085 | имя листа и позиция |
| SST | 0x00FC | таблица общих строк |
| LABELSST | 0x00FD | ячейка-ссылка на SST |
| NUMBER | 0x0203 | числовая ячейка |
| RK / MULRK | 0x027E | сжатое число |
| FORMULA | 0x0006 | формула (кэшир. значение) |
| COLINFO | 0x007D | ширина столбца |
| ROW | 0x0208 | высота строки |
| MERGEDCELLS | 0x00E5 | области объединения |
| XF | 0x00E0 | формат ячейки (стиль) |
| PALETTE | 0x0092 | пользовательская палитра |
| MSODRAWING | 0x00EC | фигуры листа (якори картинок) |
| MSODRAWINGGROUP | 0x00EB | глобальные фигуры (пул байтов) |
| FONT | 0x0031 | шрифт |

### 4.3 Модель в памяти (важно)

Разобранные данные хранятся в `$xls->sheets`:

```php
$xls->sheets[$sheetNum] = [
    'cells'     => [ строка => [ столбец => значение, ... ], ... ],   // отсчёт с 0
    'cellsInfo' => [ строка => [ столбец => ['xf'=>индекс,'rowspan'=>?,'colspan'=>?], ... ] ],
    'colWidth'  => [ столбец => px, ... ],
    'rowHeight' => [ строка => px, ... ],
    'mergeList' => [ ... области объединения (лениво) ],
];
```

- Координаты **везде отсчитываются с 0** (строка 1 = 0, столбец A = 0), как в версии xlsx.
- `cellsInfo` несёт и индекс стиля `xf`, и метки объединения `rowspan` / `colspan` (есть только у левой верхней ячейки).

### 4.4 Координаты ячеек

```php
echo SimpleXLS::coord(0, 0);   // A1
echo SimpleXLS::coord(2, 4);   // C5
```

`coord($x, $y)` преобразует координаты (отсчёт с 0) в нотацию Excel `A1` — для отладки и логов.

## V. Полный справочник API

### 5.1 Статические фабричные методы

| Метод | Возвращает | Назначение |
|---|---|---|
| `SimpleXLS::parse($file, $isData=false, $debug=false)` | `SimpleXLS\|false` | главная точка входа; `false` при ошибке |
| `SimpleXLS::parseFile($filename, $debug=false)` | `SimpleXLS\|false` | то же, что `parse($filename,false,$debug)` |
| `SimpleXLS::parseData($data, $debug=false)` | `SimpleXLS\|false` | то же, что `parse($data,true,$debug)` |
| `SimpleXLS::parseError($set=false)` | `string` | последняя ошибка (глоб. статич.) |
| `SimpleXLS::buildInfo()` | `string` | отпечаток версии |

### 5.2 Статус и ошибки

| Метод | Возвращает | Назначение |
|---|---|---|
| `$xls->success()` | `bool` | разбор успешен? |
| `$xls->error($set=false)` | `string` | ошибка уровня экземпляра |
| `$xls->parseError()` | `string` | то же, что статич. `SimpleXLS::parseError()` |

### 5.3 Метаданные листов

| Метод | Возвращает | Назначение |
|---|---|---|
| `$xls->sheetNames()` | `array` | все имена листов (индекс с 0) |
| `$xls->sheetName($index)` | `string\|null` | имя листа |
| `$xls->boundsheets` | `array` | исходная информация о листах (со смещениями) |

```php
print_r($xls->sheetNames());   // ['Sheet1', 'Sheet2']
echo $xls->sheetName(0);       // Sheet1
```

### 5.4 Чтение данных (ядро)

| Метод | Возвращает | Назначение |
|---|---|---|
| `$xls->rows($sheetNum=0, $limit=0)` | `array\|false` | 2-D массив, с 0; `$limit>0` ограничивает строки |
| `$xls->toArray($limit=0)` | `array` | псевдоним `rows(0,$limit)` |
| `$xls->rowsMerged($sheetNum=0, $fillMerged=true, $limit=0)` | `array\|false` | с учётом объединения: заполнение + метки картинок |

```php
$rows = $xls->rows();                 // все строки листа 1
$rows = $xls->rows(1);                // лист 2
$rows = $xls->rows(0, 100);           // первые 100 строк (удобно для больших файлов)

// чтение с учётом объединения: каждая объединённая ячейка имеет значение, картинки помечены img:img/...
$rows = $xls->rowsMerged(0, true);
```

> Координаты совпадают с версией xlsx: `$rows[строка][столбец]`, отсчёт с 0. Даты/числа возвращаются как исходные значения Excel (числа — дробные серийные; преобразуйте через `createDate()`).

### 5.5 Вывод HTML

```php
$xls->toHTML($sheetNum = 0, array $options = [])
```

Опции:

| Опция | По умолч. | Назначение |
|---|---|---|
| `head` | `true` | первая строка как `<th>` (жирный) |
| `class` | `'excel'` | class таблицы `<table>` |
| `escape` | `true` | HTML-экранирование текста ячеек |
| `limit` | `0` | ограничить строки, `0` = без ограничений |
| `styles` | `true` | внедрить CSS стилей Excel (шрифт/заливка/выров./граница/шир./выс.) |

```php
echo $xls->toHTML(0, ['head' => true, 'class' => 'excel', 'styles' => true]);
```

Выводит `<table class="excel" border="1">`; объединённые ячейки — настоящие `rowspan/colspan`; ячейки картинок — встроенный `<img class="xls-img">` плюс относительный путь `<span class="xls-imgpath">`.

### 5.6 Объединённые ячейки

| Метод | Возвращает | Назначение |
|---|---|---|
| `$xls->mergeCells($sheetNum=0)` | `array` | нормализованный список областей |
| `$xls->fillMerged($rows, $sheetNum=0)` | `array` | заполнить значением из `$rows` |
| `$xls->rowsMerged(...)` | `array` | чтение с учётом объединения (см. 5.4) |

Каждый элемент `mergeCells()` (согласован с xlsx `SimpleXLSXPro::mergeCells()`):

```php
[
    'ref' => 'A1:B2',   // нотация A1
    'x1' => 0, 'y1' => 0, 'x2' => 1, 'y2' => 1,
    'w' => 2, 'h' => 2,
]
```

```php
$merges = $xls->mergeCells(0);
echo count($merges);    // число областей объединения в листе 1
```

### 5.7 Извлечение изображений

```php
$xls->extractImages($dir = 'img', $relPrefix = null)
```

| Парам. | Назначение |
|---|---|
| `$dir` | каталог записи картинок (по умолч. `img`); поля показывают `img/xxx.png` для относит. каталогов |
| `$relPrefix` | явный относительный префикс в полях; выводится из `$dir`, если не задан |

Возвращает `$imageCells[лист][строка][столбец] = 'img:относит.путь'` и записывает исходные байты изображения.

```php
$imgMap = $xls->extractImages('img');   // запись в ./img/, поля img:img/...
foreach ($imgMap as $si => $rows) {
    foreach ($rows as $r => $cols) {
        foreach ($cols as $c => $tag) {
            echo "лист{$si} стр{$r} стлб{$c} есть картинка: $tag\n";
        }
    }
}
```

> Распознавание изображений — **чистый PHP, ноль зависимостей**: сначала проверяется, содержит ли файл фигуры Escher (поток OLE `Pictures` или встроенный `MSODRAWINGGROUP`); извлекает, только если это возможно. Файлы без картинок возвращают пусто без нагрузки.

### 5.8 Стиль / CSS ячейки

| Метод | Возвращает | Назначение |
|---|---|---|
| `$xls->cellCSS($sheetNum, $row, $col)` | `string` | CSS одной ячейки (шрифт/заливка/выров./граница) |
| `SimpleXLS::$IC` | `array` | встроенная таблица 66 индексированных цветов |

```php
echo $xls->cellCSS(0, 0, 0);
// напр. background:#1F3864;color:#FFFFFF;font-weight:bold;text-align:center;border:1px solid #BFBFBF;
```

Восстановление стиля охватывает: имя/размер/жирность/курсив/подчёркивание шрифта, цвет заливки (палитра + расширенный XFEXT), горизонтальное/вертикальное выравнивание, тип и цвет границ с четырёх сторон, ширину столбца (`<colgroup>`), высоту строки (`<tr>`).

### 5.9 Даты

| Метод | Возвращает | Назначение |
|---|---|---|
| `$xls->createDate($timevalue)` | `string\|false` | преобразовать серийное значение Excel в строку даты |
| `$xls->setDateTimeFormat($value)` | `void` | установить формат вывода даты (по умолч. `Y-m-d H:i:s`) |

```php
$xls->setDateTimeFormat('Y/m/d');
echo $xls->createDate(45234.5);   // 2003-10-27 12:00:00
```

> Даты Excel — это «дни с 1899-12-30 + доля суток». Библиотека исправляет баг 1900-високосного года (1900-02-29 не существует, но занимает индекс).

### 5.10 Кодировка и форматы

| Метод | Назначение |
|---|---|
| `$xls->setOutputEncoding($encoding)` | установить кодировку вывода (по умолч. UTF-8) |
| `$xls->setDefaultFormat($sFormat)` | установить формат чисел по умолчанию |
| `$xls->setColumnFormat($column, $sFormat)` | установить формат чисел столбца |

```php
$xls->setOutputEncoding('UTF-8');
```

## VI. Объединённые ячейки подробно

Excel хранит объединение как «левая верхняя ячейка имеет значение, остальные пусты» + «границы области». Библиотека предлагает две стратегии:

**Стратегия A — настоящее объединение HTML (рекомендуется для отображения)**

`toHTML()` автоматически генерирует `rowspan` / `colspan` из `MERGEDCELLS`, сохраняя содержимое левой верхней и скрывая объединённые ячейки. Визуально идентично исходному.

**Стратегия B — заполнение значением (рекомендуется для CSV/TSV/массива)**

`rowsMerged($sheetNum, true)` и `toCSV()` / `toTSV()` внутренне вызывают `fillMerged()`, копируя значение левого верхнего угла в каждую ячейку области, получая полный прямоугольник, готовый к экспорту CSV или подаче алгоритму.

```php
// только информация об объединении
$merges = $xls->mergeCells(0);

// заполнить значения обратно (можно и вручную после получения rows)
$rows = $xls->rows(0);
$filled = $xls->fillMerged($rows, 0);

// одним вызовом: заполнить значения И наложить метки картинок
$rows = $xls->rowsMerged(0, true);
```

> Пограничный случай: нижний правый угол объединения может выходить за `rows()` (напр. объединено в пустые строки). `toHTML()` и `rowsMerged()` автоматически дополняют матрицу — без смещения или пропавших столбцов.

## VII. Извлечение изображений подробно

### 7.1 Два источника изображений

Встроенные изображения xls приходят из записей фигур **Escher**. Библиотека охватывает оба пути:

1. **Поток `Pictures`** (родной Excel): именованный поток OLE; контейнер `FBSE(0xF001)` хранит байты blip напрямую.
2. **Встроенный `MSODRAWINGGROUP`(0xEB)**: стиль LibreOffice / WPS — пул байтов картинок лежит в глобальном подпотоке Workbook; нужно рекурсивно обойти контейнеры Escher, чтобы найти `BSE(0xF007)`.

`collectBlips()` сначала пробует поток `Pictures`, при пустоте откатывается к глобальному `MSODRAWINGGROUP` и рекурсивно заходит в `DggContainer` / `DgContainer`, чтобы не пропустить картинку.

### 7.2 Якоря ячеек

Картинки не всегда сидят ровно в центре ячейки. `sheetPictureAnchors($si)` разбирает `ClientAnchor(0xF010)` каждого `SpContainer(0xF004)` (9 short: строка/столбец верха/лева/низа/права + пиксельные сдвиги), получая координату левой верхней ячейки картинки, и помечает её `img:относит.путь`.

### 7.3 Правило именования файлов

```
<безопасное-имя-листа>_x<строка+1>_y<столбец+1>.<расширение>
```

Напр. `Sheet1_x2_y3.png` = картинка в листе Sheet1 строка 1, столбец 2 (отсчёт с 0). Один и тот же blip, на который ссылаются в нескольких местах, использует один файл; конфликты имён автоматически добавляют `_2`, `_3`.

### 7.4 Запись пути в поля

После извлечения текст затронутой ячейки заменяется на `img:img/xxx.png`. `toHTML()` видит префикс `img:` и выводит:

```html
<td>
  <span class="xls-imgpath">img/img/Sheet1_x2_y3.png</span>
  <img class="xls-img" src="data:image/png;base64,..." alt="">
</td>
```

- Файл на диске: исходные байты изображения (как есть, `gd` не нужен)
- Встроенный предпросмотр: `toHTML()` встраивает base64 через `data:` URI — предпросмотр одним файлом
- Относительный путь: путь в поле относителен `img/`, поэтому перенос папки сохраняет ссылки рабочими

### 7.5 Относительный против абсолютного пути

```php
$xls->extractImages('img');            // относит.: поле img:img/xxx.png, запись ./img/
$xls->extractImages('/var/www/img');   // абсолютн.: поле хранит последний сегмент img/xxx.png, запись /var/www/img/
$xls->extractImages('img', 'pics');    // явный префикс: поле img:pics/xxx.png
```

> Без `$relPrefix` и при абсолютном `$dir` поле хранит только последний сегмент каталога, избегая утечки абсолютного пути сервера на фронтенд.

## VIII. Система стилей (XF → CSS)

Стили разбираются целиком из записи BIFF `XF(0x00E0)` — внешняя таблица стилей не нужна.

### 8.1 Разбор цвета

- **Встроенные индексированные цвета**: `SimpleXLS::$IC` — стандартная таблица 66 Indexed Colors, покрывающая палитру Excel по умолчанию.
- **Пользовательская палитра**: если файл содержит `PALETTE(0x0092)`, он переопределяет соответствующие индексные цвета для точной передачи пользовательских цветов.
- **Расширенный цвет XFEXT**: `XFEXT(0x087D)` несёт истинно-цветные заливки (type 4) и границы (type 7/8/9/10). Библиотека побайтово разбирает его смещения (`xf@14`, `cnt@18`, признак `@20`) и применяет расширенный цвет заливки **только когда базовый XF помечен как solid** — избегая несоответствия «ошибочно окрашенная ячейка, которая не должна быть цветной».

```php
echo $xls->cellCSS(0, 0, 0);   // авто-слияние палитры / PALETTE / XFEXT
```

### 8.2 Выравнивание, заливка, граница

| Измерение | Источник | CSS |
|---|---|---|
| Горизонт. выравнивание | битовое поле XF (смещ. 6) | `text-align: left/center/right` |
| Вертик. выравнивание | битовое поле XF | `vertical-align: top/middle/bottom` |
| Жирность | запись FONT | `font-weight: bold` |
| Размер шрифта | запись FONT | `font-size: Npt` |
| Цвет заливки | XF смещ. 18 + палитра/XFEXT | `background: #RRGGBB` |
| Граница | XF смещ. 10 (4 nibble) + смещ. 12/14 (цвет icv) | `border: 1px solid #RRGGBB` |

> База индекса шрифта адаптируется: xlwt использует отсчёт с 0, LibreOffice / WPS — с 1. Библиотека считает только **реально используемые** индексы шрифтов для определения базы, избегая ошибочного учёта неиспользуемых шрифтов по умолчанию.

## IX. Даты и время

Excel хранит дату как число с плавающей точкой:

```
значение = дни с 1899-12-30 + доля суток
```

- `45234.5` → 2003-10-27 12:00:00
- целая часть = дата, дробная = время

```php
$xls->setDateTimeFormat('Y-m-d H:i:s');
echo $xls->createDate($cellValue);
```

**Баг 1900-високосного года**: Excel ошибочно считает 1900 високосным, резервируя индекс для 1900-02-29. Библиотека это исправляет, чтобы вывод совпадал с отображением Excel.

**Распознавание даты в ячейке**: по **формату числа** ячейки (запись формата). Если формат содержит маркеры даты `yyyy` / `dd` / `mm`, трактуем как дату; иначе как число. Используйте `setColumnFormat()`, чтобы принудительно разобрать столбец как дату.

## X. Форматы вывода (HTML / CSV / TSV)

### HTML

```php
$xls->toHTML(0, ['head'=>true,'class'=>'excel','styles'=>true]);
```

Сохраняет объединения (`rowspan/colspan`), внедряет стили Excel, встраивает картинки, восстанавливает ширину столбца / высоту строки. Подходит для предпросмотра или вставки в письмо/отчёт.

### CSV / TSV

```php
echo $xls->toCSV(0);          // BOM UTF-8 по умолчанию, чисто открывается в Excel
echo $xls->toTSV(0);          // табуляция, без BOM по умолчанию
echo $xls->toCSV(0, ',', false); // без BOM
```

CSV/TSV сначала `fillMerged()` (заполнение левым верхним), затем запись через PHP `fputcsv`, автоматически обрабатывая экранирование кавычек и переносы строк.

## XI. Обработка ошибок

Все точки входа разбора возвращают `false` при ошибке; сообщение берётся из **глобальной статики** `SimpleXLS::parseError()`:

```php
$xls = SimpleXLS::parse('bad.xls');
if ($xls === false) {
    echo 'Ошибка: ' . SimpleXLS::parseError();
}
```

| Частая ошибка | Значение | Исправление |
|---|---|---|
| пустой файл / не OLE | повреждён или не xls | убедитесь, что расширение совпадает с реальным форматом |
| нет потока Workbook | аномалия структуры OLE | режим отладки, проверьте отсутствие `BOF` |
| проблема кодировки | не-UTF-8 кириллица | `setOutputEncoding('UTF-8')` |
| лист неполный | большой файл / конкатенация CONTINUE | включите `$debug` или `rows($n, $limit)` |

**Полная проверка загрузки**:

```php
if (!isset($_FILES['xls']) || $_FILES['xls']['error'] !== UPLOAD_ERR_OK) {
    die('Загрузка не удалась');
}
$tmp = $_FILES['xls']['tmp_name'];
if (substr(bin2hex(file_get_contents($tmp, false, null, 0, 8)), 0, 8) !== 'd0cf11e0') {
    die('Не корректный файл OLE/xls');   // магия OLE D0CF11E0
}
$xls = SimpleXLS::parse(file_get_contents($tmp), true);
if (!$xls) { die(SimpleXLS::parseError()); }
```

## XII. Примечания по безопасности

### 12.1 XSS: значения экранированы, но берегите пути

`toHTML()` по умолчанию `escape=true` и экранирует текст ячеек через `htmlspecialchars`. Но поле картинки `img:` содержит **ваш собственный относительный путь** — если `$dir` берётся из пользовательского ввода, отфильтруйте его.

### 12.2 Бомба распаковки/разбора (теоретически)

xls — составной документ OLE; теоретически маленький файл может развернуться в большое содержимое. Библиотека строго обрезает поток `Pictures` по `prop['size']`, поэтому он не развернётся бесконечно. Для ненадёжных файлов обрабатывайте в песочнице/временном каталоге.

### 12.3 Утечка абсолютного пути

С `extractImages('/abs/path')` поля хранят только последний сегмент, избегая вывода абсолютного пути сервера в HTML фронтенда.

### 12.4 Тайм-аут большого файла

Огромный xls одним `toArray()` может превысить лимит времени или памяти. Читайте порциями через `rows($n, $limit)` или только нужные листы.

## XIII. Известные проблемы и подводные камни

- 🟡 **`parseError()` — глобальная статика**: при конкурентности или последовательном разборе нескольких файлов ошибка может перезаписаться. Читайте её сразу после каждого разбора или используйте уровень экземпляра `$xls->error()`.
- 🟡 **Координаты с 0**: как в xlsx, но отличаются от 1-базового UI Excel — не путайте в циклах.
- 🟠 **Ячейки формул возвращают сохранённые значения**: в xls-версии нет движка формул; ячейка формулы возвращает последнее сохранённое кэшированное значение Excel; если файл никогда не открывался/пересчитывался в Excel, кэш может быть пустым.
- 🟠 **Ведущие нули / длинные числа**: ведущие нули, сохранённые как текст, сохраняются; если как число, длинные целые могут вернуться как float (как в xlsx). При экспорте CSV при необходимости используйте `setColumnFormat()`.
- 🟢 **Распознаются только встроенные (Escher) картинки**: картинки, вставленные через «Вставить картинку», извлекаются; картинки как фон/водяной знак или ссылка вне системы якорей ячеек не помечаются.

## Приложение B: карточка API

```php
// разбор
SimpleXLS::parse($file, $isData=false, $debug=false);
SimpleXLS::parseError();
SimpleXLS::buildInfo();

// данные
$xls->rows($sheetNum=0, $limit=0);
$xls->toArray($limit=0);
$xls->rowsMerged($sheetNum=0, $fillMerged=true, $limit=0);

// листы
$xls->sheetNames();
$xls->sheetName($index);

// объединения
$xls->mergeCells($sheetNum=0);
$xls->fillMerged($rows, $sheetNum=0);

// картинки
$xls->extractImages($dir='img', $relPrefix=null);

// стиль
$xls->cellCSS($sheetNum, $row, $col);
SimpleXLS::$IC;

// вывод
$xls->toHTML($sheetNum=0, $options=[]);
$xls->toCSV($sheetNum=0, $delimiter=',', $bom=true);
$xls->toTSV($sheetNum=0, $bom=false);

// даты/кодировка
$xls->createDate($timevalue);
$xls->setDateTimeFormat($value);
$xls->setOutputEncoding($encoding);
$xls->setColumnFormat($column, $sFormat);
```

## В заключение

`SimpleXLS` и `SimpleXLSX` — близнецы-библиотеки: один стиль API, две эпохи Excel. Если вы уже используете xlsx-версию, замените `require` на `xls.php` и переименуйте класс с `SimpleXLSX` на `SimpleXLS`, чтобы плавно перейти к чтению устаревшего формата.
